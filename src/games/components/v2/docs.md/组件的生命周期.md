#

## 1. 初始化

先初始化自己的基础数据.
完成后再初始化子组件的基础数据.

当后代组件树初始化完成后, 父组件此时状态才会变更为true.

## 2. 绘制

当组件自身准备完毕后, 应当由父组件调用自身的绘制命令.
绘制中再调用子组件的绘制命令.

## 3. 更新

当组件自身状态发生变化时, 应当更新自身的显示.
在更新时告知父组件自身发生变化.
父组件判断是否需要传递给更高级的组件.
如果不需要就从自己开始处理, 不再向上传递.
父组件开始触发数据更新传递给子组件.
子组件接收到更新通知后, 也会进行自身的更新处理.
数据更新完毕后. 执行绘制命令.

## 4. 销毁

当组件不再需要时, 应当销毁自身.
销毁时先销毁子组件, 再销毁自身的资源.
销毁完成后, 父组件应当移除对该组件的引用.
也是一路传递到最终的子组件. 开始销毁.
子组件销毁准备阶段完成后告诉父组件自己准备好了.
父组件也开始准备销毁自身的资源.
一路透传到销毁的目标组件. 

当目标组件准备销毁阶段完成后. 再一路透传告诉最终子组件. 
此时最终子组件开始销毁. 并且一路向上销毁到目标组件.
